- **PharmaCO – Smarter Pharmacy, Healthier Lives**  
  A complete pharmacy management system built with ASP.NET MVC. Features include customer records, medicine inventory, order processing, image previews, autocomplete search, and invoice generation.

- **To-Do App (Angular)**  
  A feature-rich Todo application built with Angular 19. Includes priorities, due dates, search, sorting, filtering, local storage persistence, and undo/delete functionality.

- **Assignment Management System**  
  A role-based full-stack web application designed for schools and colleges to manage assignments, student submissions, and teacher evaluations.

- **Bangladesh Street Mime Council**
